# PC Assembly Session

## 1. Activity Information
- **Activity:** PC Assembly Session
- **Date:** 2 November 2026
- **Venue:** Active Learning Lab, UTM
- **Activity Type:** Group Activity

## 2. Introduction
This activity provided an opportunity to learn about computer hardware through a hands-on PC disassembly and reassembly session.

## 3. Activities Performed
During this activity, we followed the technicians' step-by-step instructions.

1. Disconnected and removed all cables.
2. Removed the blue and orange cables.
3. Removed the RAM.
4. Removed the hard disk.
5. Removed the CPU fan.
6. Reassembled the computer by reconnecting the cables and components.
7. Connected and tested the PC to check whether it could function properly.

## 4. Learning Outcomes
- Learned about different computer hardware components.
- Gained practical experience in PC disassembly and reassembly.
- Understood the importance of correct cable connections.
- Improved teamwork and communication skills.

## 5. Personal Reflection
Through this activity, I gained practical experience in handling computer hardware. I learned how different components are installed and connected inside a computer.

Working with my group members also helped me understand the importance of teamwork and following instructions carefully.

Overall, this activity improved my understanding of computer hardware and gave me valuable hands-on experience.
